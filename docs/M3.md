## 2. 交付物 2 · host 侧只读查询接口

**涉及文件**：`src/tools.js`（或新增 `src/panel/query.js`）

**要求**：给面板提供**只读**数据（不得写台账、不得改文件）：
- `members`：`name / role / mode / layer / parent / status / modelRoute / latestDeliverable / lastActiveAt`
- 谱系：按 `parent` + `layer` 组织成树（根 = 主代理）
- 文档与任务计数：`docs` 按 `tier` 计数、`tasks` 按 `status` 计数

**验收（补测试）**：查询接口对空台账、缺字段记录、单条坏记录都不得抛错（降级为空值）；断言输出字段齐。

## 3. 交付物 3 · 树视图（四个功能点）

| # | 功能 | 要求 |
|---|---|---|
| 3.1 | **点击节点跳转会话** | 有现成 API 就跳转；**没有就把该节点 session id 复制/展示出来**（并在 tab 里给一句提示），不要为此自造路由 |
| 3.2 | **角色配色标签** | 主代理 / 成员(team 词位) / 子智能体三类可见区分；角色色至少覆盖 `researcher` / `implementer` / `reviewer` / `adversary`（**对抗审查用专属色**）/ `librarian`；另带状态（running/idle/completed/failed/released）与模式（前台 one-shot / 后台 continuable）标签 |
| 3.3 | **隐藏已完成与一次性** | 过滤开关，**默认隐藏已完成的一次性(one-shot)节点**；开关状态持久化 |
| 3.4 | **合规徽章** | 每个节点可显示：契约✓ / 三档✗ / 进度✗ / 预算超限⚠ / 异源✓✗；数据来自交付物 2 的审计摘要（M4 接真实现，M3 用占位） |

**验收（人工核验清单，写进报告）**：
- 造一个 3 层谱系（含 1 个已完成 one-shot + 1 个 continuable）→ 树层级正确、默认隐藏后者以外的那类节点
- 点任一节点 → 有跳转或 id 展示
- 五个角色的卡片颜色**肉眼可区分**
- 造一条"缺三档文档"的记录 → 对应徽章变为 ✗ / ⚠
