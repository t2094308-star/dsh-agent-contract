## 2. 逐条验收（M3 五条）

### 2.1 tab 在位且可区分
- [ ] 右侧栏出现 **「契约」** tab，图标是**双方块 glyph**（无 emoji）
- [ ] 它排在「任务管理」之后（`order=120`），**两者并存**
- [ ] 点开有内容（不是空白、不是报错）

### 2.2 谱系树 + 默认隐藏
- [ ] 树根是**主代理**，成员/子智能体挂在下面；层级正确（3 层样例能看出三代）
- [ ] **默认看不到"已完成的一次性(one-shot)"节点**
- [ ] 在 tab 设置里关掉该开关 → 这些节点**出现**
- [ ] 重启应用后开关状态**保持**

### 2.3 点击跳转
- [ ] 点节点名：宿主支持 → **跳到该子智能体会话**；不支持 → 悬停/标题能看到 **session id**

### 2.4 角色配色（肉眼可区分）
- [ ] 主代理 紫 · researcher 蓝 · implementer 绿 · reviewer 橙 · **adversary 红（专属）** · librarian 青 · 未知 灰
- [ ] 每节点还带**状态**（running/idle/completed/failed/released）与**模式**（前台/后台）标签

### 2.5 徽章
- [ ] 每节点有 **5 枚**徽章：契约 / 三档 / 进度 / 预算 / 异源
- [ ] **契约**：子智能体 ✓，主代理为"不适用"
- [ ] **异源**：对抗审查 vs **同层实现者**模型不同 → ✓；相同 → ✗
- [ ] **三档 / 进度**：显示为灰/半透明，提示"**数据源待接**"（M4 才接真审计，这是**预期**不是 bug）

## 4. 常见"不是 bug"的情况

- **三档/进度徽章灰**：预期（M3 只有血缘数据；真审计在 M4）
- **只有 1 层树**：若还没派过子智能体，正常；按 §1 造数据
- **tab 不出现**：先确认"真的重启过"（托盘 Quit 而不是关窗口）；再确认插件在 profile 里；再确认 better-sidebar 启用
