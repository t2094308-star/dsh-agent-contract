## 1. 交付物 1 · `audit_scan`（检查项实现）

**涉及文件**：`src/audit/checks.js`、`src/audit/report.js`（已有骨架则补齐）

**检查项**（与 §5.7 对齐；`audit.checks` 从 config 读取开关）：

| 检查项 | 判定 |
|---|---|
| `missing_doc` | 有产出义务的成员在产出目录找不到对应档 |
| `over_budget` | 装配片段超软限（≤30% 仅提醒）或超硬限；或文档超 `oversize_doc`（三级强警告、二/一级只记） |
| `unfilled_slot` | 契约文本里残留未替换的槽位（**须剔除已替换取值与 `[Agent进度]` 这类真实目录名**） |
| `stale_progress` | 进度档 >400 字，或最后更新早于成员最后活动 |
| `cross_vendor` | `adversary` 的模型家族与 `implementer` 相同（= 非真对抗） |
| `ghost_run` | 谱系里有 one-shot 节点但无产出档 |
| `orphan_task` | 成员已 `released` 但任务未结 |
| `unreleased_run` | 有活动但无释放记录 |
| `doc_misfiled` | 文档不在规定类目录 / `docs` 根存在散 `.md`（**只报不动**；已实现，勿回退） |
| `doc_meta_missing` | 缺 front-matter / 固定小节；**`legacy=true` 或 `tier=0` 的档不参与** |
| `doc_tags_stale` | 正文已改但 `keywords` 未更新 |
| `archive_suggest` | 建议归档（按批次/时间阈值），**只建议** |

**输出**：
```js
{ level: 'red' | 'yellow' | 'green', items: [{ check, level, target, detail }], humanReport: string, counts }
```
`humanReport` = 给主代理/馆员看的**人话清单**（按严重度排序，每条含 路径 + 一句话原因 + 建议动作）。

**验收（每项都要正反用例）**：
- 每项检查：造一条**命中**的假数据 → 报出；造一条**不命中**的 → 不报
- **警告制**：审计返回结果即可，**断言不抛错、不中断**、不改动任何文件（跑前后目录 sha256 一致）
- `legacy` 与 `tier=0` 的档：不参与 `doc_meta_missing`（回归位，勿破）
- `unfilled_slot`：`D:\Blockdustry\[Agent进度]` 这类真实目录名**不得**误报
- 未知的 `audit.checks` 项：**报错**（不静默忽略），避免配置写错却以为在查

3. **命名与档级规范化**：按 `<任务号>_<标题>_L1|L2|L3.md` 改名/移动；**改名必须更新引用**
4. **归档与去重**：重复档合并、按批次/时间移入 `archive/<分片>/`
5. **术语表维护**：统一术语与同义词（供 `keywords` 自动展开）
6. **legacy 全量回填**（从"试跑"升为全量，限量参数可配）

**触发**：① 批次完成 ② `audit_scan` 出现红/黄 ③ 单任务收档的轻量巡检（闸门：`needs_librarian` 非空才唤醒）

**验收**：
- 造一组需治理的假数据（缺档 + 命名不规范 + 重复档 + 缺元数据）→ 馆员一轮下来：报告齐、索引更新、命名规范、归档建议落地

- 幂等：同一批再跑一次 → `changed=false`

## 3. 交付物 3 · 分片与归档策略

**要求**：
- `archive/` 分片：按**批次**（`archive/P1/…`）或**时间**（`archive/2026-08/…`）——二选一并写进 `DESIGN.md` §5.5；默认取**时间分片**（与批次解耦）
- `archive_suggest` 阈值可配（例如：档龄 > 90 天 且 所属任务已结）
- 归档动作由**馆员**执行（移动 + 留痕 + 更新引用）；**审计只建议**

**验收**：造 3 篇"已结任务 + 超阈值"的档 → `archive_suggest` 报出；馆员执行后档在 `archive/<分片>/`，引用已更新，根目录无残留。
